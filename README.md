# multimodal-ai-assistant
The Multimodal AI Assistant is an advanced artificial intelligence system designed to interact with users through multiple input formats such as text, voice, and images. The goal of this project is to build a smart virtual assistant that can understand different types of data simultaneously, context-aware responses in real time.
# Multimodal AI Assistant

## Features
- Text conversation using LLMs
- Voice input using Whisper AI
- Image processing using OpenCV
- Speech output using TTS
- Smart AI automation

## Tech Stack
Python, LangChain, OpenAI/Gemini API, Whisper, OpenCV

## Run Project
pip install -r requirements.txt
python app.py
